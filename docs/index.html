Motivation & Architecture

Why Semantic Pattern Matching?

Modern software is increasingly event-driven and semantic. But developers are forced to choose between rigid regex/switches and slow, expensive LLM prompts.

✕

LLM Prompt Bloat

Prompting an LLM for classification takes 300ms–2000ms, costs API credits on every turn, and introduces unpredictable prompt drift.

!

Hallucinated Confidence

When asked for confidence, LLMs output uncalibrated text strings like "0.99" even for false predictions. They lack true mathematical probability distributions.

✓

The Cascade Solution

hev processes 80% of obvious cases in 0.12ms locally for free with 98% recall. Only uncertain cases (< 0.8) are escalated to heavy models.

The 10,000 Item Test

Classifying 10,000 inbound webhook logs with an LLM costs ~$20 and takes 5 minutes. With hev, all 10,000 items are triaged in 1.2 seconds on a single CPU core for $0.

System Design & Mechanics

How hev Works

Three mathematical and ergonomic primitives that turn natural language and application state into deterministic control flow.

1

Intent Reflection

hev inspects argument types dynamically: Objects activate Pattern Matching, Arrays trigger Zero-Shot Classification, and Strings invoke Boolean Predicates. Auto-curries when called data-last.

Zero configuration bags
2

Subword N-Gram Hash

Extracts word stems, word bi-grams, character 3-grams, and semantic synonym clusters. Projects them into a 512-dimensional vector via FNV-1a sign hashing in < 0.05ms.

Typo and morphology resilient
3

Calibrated Softmax

Calculates unit cosine similarity across all candidate labels and normalizes scores using temperature-scaled softmax. Produces calibrated probabilities that satisfy the Brier score test (< 0.10).

Mathematical confidence

Code & Usage

Three-line quick start, confidence guards, and functional currying.

Pattern Matching with Confidence Guards
import hev from 'hev';

await hev(text, {
  'bug @ >0.8': (t, meta) => fileJira(t, meta.score),
  'bug':        (t) => queueTriage(t),
  'billing':    (t) => openStripe(t),
  _:            (t) => logToInbox(t),
});
Runs branch handler in single forward pass.
Point-Free Functional Pipelines
const triage = hev(['bug', 'feature', 'billing']);
const isSpam = hev.is('spam');

const tickets = await fetchTickets();
const categories = await Promise.all(tickets.map(triage));
const badEmails = await emails.filterAsync(isSpam);
Auto-curries when called with patterns only.
